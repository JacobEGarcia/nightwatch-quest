# Nightwatch: Field Battery

An original 3D WebXR field game for Meta Quest 3. Open the HTTPS GitHub Pages URL in Meta Quest Browser and select **Enter Quest VR**. The right controller's trigger selects an aircraft when the ray hits it, then fires the selected track on a second press (or fires when aimed away). On an ending, the headset returns from immersive mode to show the result and replay controls. A stereo world-space panel shows IFF and the watch state.

Desktop and touch fallback: drag to look, tap or click an aircraft to track it, and use the Fire button or Space to launch. Three watches, finite interceptors, friendly losses and hostile impacts affect the ending.

Based on the mood and air-defense premise of the supplied video, without its footage, branding, music or assets. The game has been tested in desktop/headless browser rendering, not on a physical Quest 3. WebXR availability and headset performance are not yet verified on hardware.
